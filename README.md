# Wheel of Affluence Ruby Odds

A FastAPI app that models the Goodgame Empire "Wheel of Affluence" ruby jackpot
mechanic and lets you calculate, for a given number of affluence tickets:

- Expected rubies (exact, closed-form)
- Median outcome and probability of any jackpot at all (Monte Carlo)
- Probability of ending up with at least X rubies, as a live curve

The model was reverse-engineered from a community spreadsheet
(`WoA 2024 + Boxes.xlsx`): every ticket opens one box, the box tier climbs a
fixed 9-tier ladder based on cumulative tickets spent, and each box has a
small independent chance of landing on that tier's ruby jackpot. See
`data/ruby_model.json` for the exact tier thresholds, odds, and jackpot
amounts, plus notes on how each was derived.

## Project layout

```
main.py                 FastAPI app + routes
model.py                Probability model (tier ladder, exact EV, Monte Carlo simulation)
data/ruby_model.json    Source-of-truth tier data + derivation notes
static/index.html       Front end
static/styles.css
static/app.js           Calls the API and renders the chart
requirements.txt
render.yaml             Render deploy config
```

## API

- `GET /api/model` — the 9-tier ladder (ranges, jackpot amounts, odds per box)
- `GET /api/calculate?tickets=2000&threshold=500000&trials=30000` — expected
  rubies, median, P(any jackpot), P(≥ threshold), and a probability curve
- `GET /docs` — interactive OpenAPI docs (auto-generated by FastAPI)
- `GET /health` — health check

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open http://127.0.0.1:8000

## Deploy on Render

1. Push this repo to GitHub (already done if you're reading this from the repo).
2. In Render, **New + → Web Service**, connect the repo. Render will pick up
   `render.yaml` automatically, or you can set manually:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. Deploy. Render assigns a public URL serving the calculator at `/`.
