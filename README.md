# Wheel of Affluence Reward Odds

A FastAPI dashboard that models the Goodgame Empire "Wheel of Affluence" box
ladder and lets you calculate, for a given number of affluence tickets and a
chosen reward type (Rubies, Construction Tokens, Upgrade Tokens, or Sceats):

- Expected amount (exact, closed-form)
- Median outcome and probability of any reward at all (Monte Carlo)
- Probability of ending up with at least X, as a live curve
- The full distribution of likely outcomes, with a trailing "> cutoff"
  bar that shows how much probability mass is in the long tail
- 95% confidence interval (2.5th–97.5th percentile) for every reward type

The model was reverse-engineered from a community spreadsheet
(`WoA 2024 + Boxes.xlsx`): every ticket opens one box, the box tier climbs a
fixed 9-tier ladder based on cumulative tickets spent, and each box has a
small independent chance of landing on that tier's reward slot. See
`data/reward_models.json` for the exact tier thresholds, odds, and reward
amounts, plus notes on how each was derived.

**What's actually verified vs. guessed.** All four reward types shipped here
share the same cross-check: the workbook's own reward icon *prints* the
exact same number as the formula's per-tier multiplier, tier by tier — not
a guess. Rubies: 50,000 → 1,000,000 (ruby-gem icon). Construction Tokens:
16 → 320 (crossed-hammers icon). Upgrade Tokens: 32 → 640, exactly double
Construction Tokens (upward-arrow icon). Sceats: 20 → 100 (cracked-stone-shard
icon). An earlier version shipped a "Construction Tokens" reward that
*assumed* a flat amount of 1 per hit with no such cross-check; that
assumption was wrong and was replaced with the verified figures above.

## Project layout

```
main.py                     FastAPI app + routes
model.py                    Probability model (ladder, exact EV, Monte Carlo, PMF/CCDF/CI builders)
data/reward_models.json     Source-of-truth ladder + per-reward odds/amounts + derivation notes
static/index.html           Overview page (stat tiles, "at least X" curve, outcome distribution)
static/confidence.html      Confidence-interval page (95% range per verified reward type)
static/styles.css           Shared dashboard styling (sidebar/nav/cards, light+dark)
static/common.js            Shared formatting + ticket-input syncing helpers
static/overview.js          Overview page logic
static/confidence.js        Confidence-interval page logic
requirements.txt
render.yaml                 Render deploy config
```

## API

- `GET /api/model` — the shared 9-tier ladder plus every reward type's odds/amounts
- `GET /api/calculate?tickets=2000&threshold=500000&reward=rubies&trials=30000` —
  expected value, median, P(any reward), P(≥ threshold), a probability
  curve, and a binned outcome distribution (ascending, with a trailing
  "> cutoff" bucket for the tail). `reward` is one of `rubies`,
  `construction_tokens`, `upgrade_tokens`, `sceats`.
- `GET /api/confidence?tickets=2000&trials=30000` — 95% CI, median, and
  expected value for every reward type at once
- `GET /docs` — interactive OpenAPI docs (auto-generated by FastAPI)
- `GET /health` — health check

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open http://127.0.0.1:8000 (Overview) and http://127.0.0.1:8000/confidence

## Deploy on Render

1. Push this repo to GitHub (already done if you're reading this from the repo).
2. In Render, **New + → Web Service**, connect the repo. Render will pick up
   `render.yaml` automatically, or you can set manually:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. Deploy. Render assigns a public URL serving the dashboard at `/`.
