# Wheel of Affluence Ruby Odds

A FastAPI dashboard that models the Goodgame Empire "Wheel of Affluence" box
ladder and lets you calculate, for a given number of affluence tickets:

- Expected rubies (exact, closed-form) and Construction Tokens
- Median outcome and probability of any ruby jackpot at all (Monte Carlo)
- Probability of ending up with at least X rubies, as a live curve
- The full distribution of likely ruby outcomes
- 95% confidence intervals (2.5th–97.5th percentile) for both reward types

The model was reverse-engineered from a community spreadsheet
(`WoA 2024 + Boxes.xlsx`): every ticket opens one box, the box tier climbs a
fixed 9-tier ladder based on cumulative tickets spent, and each box has a
small independent chance of landing on that tier's reward slot. See
`data/reward_models.json` for the exact tier thresholds, odds, and reward
amounts, plus notes on how each was derived and how confident that
derivation is (rubies are verified against a printed value on the workbook's
own icon; Construction Tokens are a good-faith reconstruction).

## Project layout

```
main.py                     FastAPI app + routes
model.py                    Probability model (ladder, exact EV, Monte Carlo, PMF/CCDF/CI builders)
data/reward_models.json     Source-of-truth ladder + per-reward odds/amounts + derivation notes
static/index.html           Overview page (stat tiles, "at least X" curve, outcome distribution)
static/confidence.html      Confidence-interval page (rubies + construction tokens)
static/styles.css           Shared dashboard styling (sidebar/nav/cards, light+dark)
static/common.js            Shared formatting + ticket-input syncing helpers
static/overview.js          Overview page logic
static/confidence.js        Confidence-interval page logic
requirements.txt
render.yaml                 Render deploy config
```

## API

- `GET /api/model` — the shared 9-tier ladder plus every reward type's odds/amounts
- `GET /api/calculate?tickets=2000&threshold=500000&reward=rubies&trials=30000` —
  expected value, median, P(any jackpot), P(≥ threshold), a probability
  curve, and a binned outcome distribution. `reward` is `rubies` or
  `construction_tokens`.
- `GET /api/confidence?tickets=2000&trials=30000` — 95% CI, median, and
  expected value for every reward type at once
- `GET /docs` — interactive OpenAPI docs (auto-generated by FastAPI)
- `GET /health` — health check

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open http://127.0.0.1:8000 (Overview) and http://127.0.0.1:8000/confidence

## Deploy on Render

1. Push this repo to GitHub (already done if you're reading this from the repo).
2. In Render, **New + → Web Service**, connect the repo. Render will pick up
   `render.yaml` automatically, or you can set manually:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. Deploy. Render assigns a public URL serving the dashboard at `/`.
